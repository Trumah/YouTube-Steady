YOUR PLAYER, YOUR SETTINGS

Tune the view to the footage.

Horizontal and vertical compensation use the DePan / FFTW WebAssembly core. Zoom, cutoff, damping and motion limits are available inside the player. Audio, seeking, speed and fullscreen stay with YouTube.

Zoom1.06× by default. Use 1.00× to keep the full frame; moving borders can expose black edges.
SmoothingLower cutoff follows camera motion more slowly. Damping controls response and rebound.
Advanced controlsSource-pixel limits, search windows, confidence and interpolation remain adjustable.

A SMALL, LOCAL INSTALL

Four steps to your first frame.

This release is installed manually in desktop Chrome. Keep the extracted folder after loading it.

  1. Download and extract

    Extract the extension ZIP into a permanent folder, keeping every file and the _locales directory together.

  2. Open Extensions

    In Chrome, choose Extensions → Manage extensions, then enable Developer mode.

  3. Load the folder

    Choose Load unpacked and select the extracted folder containing manifest.json.

  4. Open a YouTube video

    Refresh an existing video page. Select Stabilize in the player to adjust settings or restore the original view.

Updating? Replace the files in your existing extension folder, reload its card in Manage extensions, and refresh YouTube.

KNOW WHAT TO EXPECT

Useful compensation.
Real-world limits.

Global translation cannot fix every shot. Rotation, zoom, rolling shutter and large foreground movement can confuse the estimate. Unreadable or protected frames return to the original player.

Will every video play at full frame rate?

No. Processing depends on the device, video and speed. The latest synthetic 1080p/30 test measured about 29.2 fps with dropped frames. Strict cadence checks did not pass. Higher speeds, 48/60 fps and 4K are not guaranteed.

Does my video leave this device?

The extension processes frames locally and uses storage for preferences. It adds no analytics, remote translation or video uploads. YouTube and any payment service still have their own privacy practices.

What about PiP, casting and HDR?

Picture-in-picture and casting use the original video. HDR output is not calibrated. Desktop Chrome 120+ is required; other browsers have not been separately qualified.
