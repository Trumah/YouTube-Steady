A SMALL, LOCAL INSTALL

Four steps to your first frame.

This release is installed manually in desktop Chrome. Keep the extracted folder after loading it.

  1. Download and extract

    Extract the extension ZIP into a permanent folder, keeping every file and the _locales directory together.

  2. Open Extensions

    In Chrome, choose Extensions → Manage extensions, then enable Developer mode.

  3. Load the folder

    Choose Load unpacked and select the extracted folder containing manifest.json.

  4. Open a YouTube video

    Refresh an existing video page. Select the camera stabilization icon at the lower right of the player to adjust settings or restore the original view.

Version 2.9.3 fixes core loading with packaged local WASM data. Replace every file in the existing extension folder, reload the extension in Chrome and refresh existing YouTube pages. Personal defaults saved in 2.8 or later are retained; older processing settings use the new system defaults. All features remain free with optional one-time support.

KNOW WHAT TO EXPECT

Useful compensation.
Real-world limits.

Global translation cannot fix every shot. Rotation, zoom, rolling shutter and large foreground movement can confuse the estimate. Unreadable or protected frames return to the original player.

Will every video play at full frame rate?

No. Processing depends on the device, video and speed. Q changes the workload substantially. Synthetic 4K frame analysis on one PC took about 24 ms at Q=25%, 45 ms at 50%, and 182 ms at 100%, before decode/output costs. The chosen Q is kept during slow processing; measured fps and timing help you decide.

Does my video leave this device?

The extension processes frames locally and uses storage for preferences. It adds no analytics, remote translation or video uploads. YouTube and any payment service still have their own privacy practices.

What about PiP, casting and HDR?

Picture-in-picture and casting use the original video. HDR output is not calibrated. Desktop Google Chrome 120+ is required. Microsoft Edge and other browsers have not been validated.
