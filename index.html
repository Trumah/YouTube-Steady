INSTALL FROM THE CHROME WEB STORE

Four steps to your first frame.

Install in desktop Google Chrome. Chrome manages updates for store installations.

  1. Open the store listing

    Use Add to Chrome above to open Video Stabilizer in the Chrome Web Store.

  2. Confirm installation

    Choose Add to Chrome, review the requested access, and confirm Add extension.

  3. Open a YouTube video

    Open a video in desktop Chrome, or refresh a video page that was already open.

  4. Adjust the view

    Select the camera stabilization icon at the lower right of the player. Turn off Enable to see the original video; Apply confirms and remembers settings for new videos, tabs and browser restarts. My default is a separate preset you can restore manually.

Store installations receive updates through Chrome. All features are free, with optional one-time support and no subscription.

Manual installation or an existing ZIP copy

For manual installation, download and extract the ZIP into a permanent folder. In Chrome, open Extensions → Manage extensions, enable Developer mode, then choose Load unpacked and select the folder containing manifest.json.

Download ZIP

Store and manually loaded copies are separate installations. Before using the store copy in the same Chrome profile, disable the manual copy. Saved settings do not transfer automatically. Manual copies can still be updated in place, reloaded in Chrome, and followed by a YouTube refresh.

KNOW WHAT TO EXPECT

Useful compensation.
Real-world limits.

Global translation cannot fix every shot. Rotation, zoom, rolling shutter and large foreground movement can confuse the estimate. Unreadable or protected frames return to the original player.

Will every video play at full frame rate?

No. Processing depends on the device, video and speed. Q changes the workload substantially. Synthetic 4K frame analysis on one PC took about 24 ms at Q=25%, 45 ms at 50%, and 182 ms at 100%, before decode/output costs. The chosen Q is kept during slow processing; measured fps and timing help you decide.

Does my video leave this device?

The extension processes frames locally and uses storage for preferences. It adds no analytics, remote translation or video uploads. YouTube and any payment service still have their own privacy practices.

What about PiP, casting and HDR?

Picture-in-picture and casting use the original video. HDR output is not calibrated. Desktop Google Chrome 120+ is required. Microsoft Edge and other browsers have not been validated.
